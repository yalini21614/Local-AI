# 📍 Local Search & Place Assistant

A location-based web application that helps users discover nearby restaurants, food spots, and other places through Google Maps search. Users can search for places, detect their location, and explore nearby listings with directions.

## ✨ Features

- 🔎 **Smart Place Search** – Search for restaurants, biryani shops, and nearby places.
- 📍 **Detect My Location** – Use the location feature to find places around you.
- 🗺️ **Google Maps Integration** – Open live Google Maps search results.
- ⭐ **Ratings & Reviews** – Explore ratings and reviews available on Google Maps.
- 🧭 **Location-Based Search** – Find places near a selected or detected location.
- 📱 **Responsive Interface** – Simple and user-friendly design.
- ⚡ **Quick Navigation** – Access nearby places and directions easily.

## 🛠️ Technologies Used

- **Python** – Application logic
- **HTML5** – Webpage structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Search and location interactions
- **Google Maps** – Place discovery and directions
- **Geolocation API** – Detect the user's location, with permission

## 📸 Application Preview

The application provides a simple search interface with location detection and a direct link to Google Maps results.

**Example:** Search for `biryani` to explore nearby biryani restaurants and view their ratings, reviews, and directions on Google Maps.

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Visual Studio Code
- A modern web browser
- Internet connection for Google Maps

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd local-search-place-assistant
```

**3. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python app.py
```

Open the local URL displayed in the terminal to access the application.
